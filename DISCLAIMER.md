# Disclaimer

PM Unleashed is an independent reference implementation and is not affiliated with, endorsed by, or sponsored by Atlassian.

The MCP servers can read and, when explicitly configured, modify Atlassian Cloud data. You are responsible for:

- validating permissions and scopes;
- testing in `preview` mode first;
- limiting write access to trusted users and environments;
- reviewing all generated changes before applying them;
- complying with your organization's security, data protection, and software governance rules.

Atlassian APIs and field schemas may vary across tenants. Discovery tools are provided to reduce hardcoded assumptions, but they do not remove the need for human review.
